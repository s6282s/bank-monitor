БАНКОВСКИЙ МОНИТОРИНГ PWA v0.4

Добавлен клиентский запрос GET /api/organizations для автоматической загрузки актуального справочника.
Приложение не показывает непроверенный набор как полный актуальный реестр ЦБ.

Для запуска API: pip install flask openpyxl; python server/app.py
Для импорта официальной выгрузки: python server/import_registry.py /путь/к/официальному_реестру.xlsx ГГГГ-ММ-ДД
После импорта API отдаёт подтверждённый снимок данных. Для полностью автоматического обновления без файлов нужен размещённый сервер, источник машиночитаемых данных ЦБ и периодический сборщик. Этот этап ещё НЕ подключён.

Справочник обновляется при открытии приложения и вручную по кнопке, если API доступен.
В офлайне используется последний сохранённый каталог.
Новости и уведомления остаются демонстрационными.
